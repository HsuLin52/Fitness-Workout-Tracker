# Fitness Workout Tracker

A Spring Boot web application that allows users to manage exercises, create workout plans, record completed workouts, track calories burned, search workout history, and view weekly or monthly progress.

## Technologies Used

- Java 17
- Spring Boot
- Spring MVC
- Thymeleaf
- Spring Data JPA
- MySQL
- Maven
- HTML
- CSS

## Requirements

Before running the project, install:

- Java JDK 17
- MySQL or XAMPP
- Git
- Visual Studio Code or IntelliJ IDEA

## Database Setup

1. Start MySQL.
2. Open phpMyAdmin or another MySQL client.
3. Create a database named:
